# Unidad 1: Planificación

Esta carpeta contiene los documentos de planificación del proyecto FitBalance.

## Contenido
- Modelo Canvas
- Requerimientos funcionales y no funcionales
- Documentación PMBOK

## Descripción del proyecto
FitBalance es una plataforma de nutrición, entrenamiento y seguimiento físico que conecta a los usuarios con profesionales para mejorar su salud y condición física.
